# Relay Rider EV-Focused TDM Landing Page

Standalone, StackBlitz-ready landing page for Relay Rider, an employer- and
institution-funded commuter coordination research platform from Common Pathways
Technologies.

## Product posture

- Research beta / pre-pilot
- Battery-electric routes prioritized, with eligible hybrid support
- Planned routes and adult commuter route requests
- Public Safe Anchor Points
- Administrative review before pilot activity
- No live payments, public booking, dispatch, or guaranteed transportation

## Run

```bash
npm install
npm start
```
